What Your File Needs

Columns can be in any order and named however you like: you match them up after uploading.

Column What Goes In It Needed
Code sku Text Example: TSHIRT-RED Required
Price price A number Example: 19.99 Optional
Released released A date (written as d/m/Y) Optional
Tags tags Text (several, separated by |) Optional
Status status Text (one of draft, publish) Optional
